# n. Northling Arch — v0.1.0 Beta 3

Личное окружение **Arch Linux + Hyprland** в тёмной индиго-лавандовой теме **Northling Midnight**
(палитра сайта [northling.space](https://northling.space)). Один установщик — и конфиги на месте.

> Beta: написано и проверено на тестовой «поддельной» системе, на живом Arch ещё не обкатано.
> Если что-то сломалось — смотри раздел «Если всё плохо» ниже.

## Что внутри

- **Hyprland** (конфиг на Lua, синтаксис 0.57), Hyprlock, Hypridle (блокировка 10 мин, сон 30 мин)
- Клик по часам в панели показывает ещё и дату (по-русски); наведи — календарь на месяц
- **Waybar «Острова»** — плавающие стеклянные блоки, рабочие столы-«пилюли», мини-метрики CPU/RAM/GPU, плеер
- **Виджеты рабочего стола**: большие часы, дата, календарь, погода (твой город), CPU/RAM/GPU, сеть, плеер с кнопками
- **SwayNC** (уведомления), **Rofi** (лаунчер), **Kitty**, **Dolphin**
- **Экран входа SDDM** в теме Northling Midnight (включается только после проверки)
- **Zsh** + Oh My Zsh + Powerlevel10k, fastfetch
- Тема GTK/Qt, **официальный VS Code** (из AUR) с темой Northling Midnight
- Обои: 3 стандартных + 2 фурри, смена через `northling wallpaper`
- NVIDIA-настройки включаются только если найдена видеокарта NVIDIA

Не делает: не трогает Windows и загрузчик, не меняет драйвер NVIDIA, не ставит Bluetooth,
не удаляет твои файлы и обои.

## Установка (первый раз)

**Делай это из TTY, не из Hyprland!** Обновление системы под живой сессией может погасить монитор.
Нажми **Ctrl+Alt+F3**, войди логином и паролем и вставь:

```bash
git clone https://github.com/Oxiety/nyarch.git ~/nyarch && cd ~/nyarch && bash install.sh
```

Установщик сам всё спросит (ответы «д» / «н»), покажет план и только потом начнёт. Перед заменой любого
конфига делается **бэкап** в `~/.local/share/northling/backups/`. Посмотреть заранее без изменений: `bash install.sh --dry-run`.
Если запустить его из графической сессии, он остановится и объяснит, как перейти в TTY.

## Обновление (когда уже установлено)

Переустанавливать не нужно. Есть два режима:

| Что | Команда | Где можно запускать |
|---|---|---|
| **Дизайн и конфиги** (быстро) | `northling update` | прямо в Hyprland |
| **Всё**: система, пакеты, конфиги | `northling update --full` | только из TTY |

`northling update` сам подтягивает свежую версию из GitHub, делает снимок твоих конфигов и применяет изменения
(перезапускает Waybar, виджеты, перечитывает Hyprland). Если запустить `install.sh` на уже установленной системе,
он предложит обновление вместо переустановки. Если в новой версии появились новые пакеты — быстрое обновление скажет,
что нужен `--full`.

## Виджеты рабочего стола

Слева — часы, дата, календарь. Справа — погода, система (CPU/RAM/GPU/сеть) и плеер (появляется, когда что-то играет).
Настройки: `northling widgets config` (файл `~/.config/northling/widgets.json`):

- **Погода**: `northling widgets city Калининград` (подставь свой город) — и всё. Можно и точные `latitude`/`longitude` в конфиге. Данные — Open-Meteo, ключ не нужен. Адреса в репозитории нет.
- Любой виджет можно выключить (`"enabled": false`), поменять отступы и ширину (`layout`).
- Управление: `northling widgets start|stop|restart|status`.
- Нужны пакеты `python-gobject`, `gtk3`, `gtk-layer-shell` (ставятся полным обновлением/установкой).

## Экран входа (SDDM)

Тема ставится вместе с проектом, но **включается только после проверки**: установщик запускает её в тестовом режиме
и включает, если нет ошибок. Вручную: `northling sddm test` → `northling sddm enable` (или `disable`).
Фон экрана входа = копия обоев: `northling sddm sync`.

Если старая тема (например `sddm-astronaut`) всё ещё показывается — её настройка `Current=` перебивает нашу. `northling sddm enable` найдёт такие строки, закомментирует их (с бэкапом) и включит нашу тему. `northling sddm status` покажет, что мешает.

Если экран входа сломался: **Ctrl+Alt+F3** → логин → `northling sddm disable` (или `sudo rm /etc/sddm.conf.d/zz-northling-theme.conf`) → `reboot`.

Чёрный экран ~3 секунды при входе: причину по гаданию не чиним. `northling diag` собирает логи SDDM/NVIDIA/Hyprland — пришли вывод.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Super+Q | Терминал |
| Super+E | Файлы (Dolphin) |
| Super+R | «Пуск»: поиск, приложения, установка программ, буфер, бинды, настройки |
| Super+A | Центр управления (звук, Wi-Fi, ночной и игровой режим) |
| Super+G | Игровой режим вкл/выкл |
| Super+Shift+R | Запасной лаунчер (rofi) |
| Super+C | Закрыть окно |
| Super+L | Блокировка |
| Super+V | Буфер обмена (история + закреплённое) |
| Super+Space / F / P / J | Плавающее / полный экран / pseudo / раскладка |
| Super+1…0 | Рабочие столы (Shift — перенести окно) |
| Print / Shift+Print | Скриншот области / экрана |
| Alt+Shift | Раскладка EN/RU (текущая видна в панели, клик по ней тоже переключает) |
| Super+M | Выход из Hyprland |

## Что ещё умеет

- **Установка программ без терминала**: Super+R → вкладка «Установка», ищет в репозиториях Arch и AUR, ставит кнопкой (пароль спросит в окне терминала).
- **Снимки системы**: `northling snapshot setup` (один раз выбрать диск в окне Timeshift), дальше `northling update --full` делает снимок сам; откат — `northling snapshot restore`.
- **Liquid Glass** (по желанию): `northling glass on` — стеклянные панели с размытием и бликами, `off` — вернуть обычный вид. Также плитка в центре управления (Super+A).
- **Норт** — маскот системы (фурсона автора): стикеры на рабочем столе, в «Пуске», на экране блокировки и входа. Клик по нему на столе меняет стикер, `northling mascot list` — весь список.
- **Док**: наведи мышь на нижний край экрана. Закреплённые программы — `~/.config/northling/dock.json`. `northling dock restart`.
- **Смена обоев по таймеру**: `northling-wallpaper --loop 30` (каждые 30 минут), `--stop` — остановить.
- **KDE Connect**: телефон ↔ ПК; на телефоне поставь приложение KDE Connect, на ПК индикатор стартует сам.
- **Игры**: при установке можно выбрать Steam/MangoHud/GameMode (нужен включённый multilib).

## Настройка

- **Монитор**: строка `hl.monitor` в `~/.config/hypr/hyprland.lua`. Сейчас режим `"preferred"` (родной режим монитора — самый безопасный). Хочешь явно 120 Гц — посмотри `hyprctl monitors`, найди режим и впиши, например, `"1920x1080@120"`.
- **Сон/блокировка**: `~/.config/hypr/hypridle.conf` (`timeout = 600` и `1800`).
- **Цвета**: `themes/northling-midnight/colors.env`, активная палитра — в конфигах.
- **Ошибки конфига**: `hyprctl configerrors`.

## Если всё плохо

1. Ctrl+Alt+F3 → логин → `northling doctor` (или `bash ~/nyarch/uninstall.sh`).
2. Старый `hyprland.lua` лежит в `~/.local/share/northling/backups/`.
3. Пришли вывод установщика или `hyprctl configerrors` — разберёмся.

## Известные ограничения (v0.2)

- Виджеты и тема SDDM написаны без возможности запустить их на живой системе: возможны косметические правки после первого запуска.
- Чёрный экран SDDM (~3 с) не диагностирован — нужны логи (`northling diag`).
- Размытие (blur) под виджетами и панелью не включено: нужны layer-правила Hyprland, их синтаксис в Lua-конфиге я не подтвердил.
- Из двух недостающих фурри-обоев найдены только твои 2; к ним — 3 сгенерированных стандартных.
- Имена пакетов сверяются с репозиториями во время установки; отсутствующие пропускаются с предупреждением.
- Старые wofi / mako / thunar остаются в системе, но не используются.

## VS Code и Windows

Тема и настройки ставятся на Linux автоматически. Для Windows: `themes/vscode/install-windows.ps1`
(ставит `.vsix` из `themes/vscode/dist`). Выбрать тему: Ctrl+K Ctrl+T → Northling Midnight.
Терминал: тема Powerlevel10k — твой файл `~/.p10k.zsh` из Windows, он же лежит в `dotfiles/zsh/p10k.zsh`.

`bash tests/run-mock-tests.sh` — прогон установки, повтора, правок, удаления и обновления на моках.
