# Changelog

## 0.1.0-beta.5
- «Пуск» Northling (`northling start`, Super+R, клик по «n.»): лавандовый логотип «n.», строка поиска по приложениям, закреплённые приложения, калькулятор («2+2*3»), `> команда` в терминале, `? запрос` в интернете.
- Вкладка «Бинды»: гайд по всем горячим клавишам на русском, фильтруется поиском.
- Вкладка «Настройки»: переключатели виджетов, стиль часов, город погоды, выбор обоев с миниатюрами, быстрые действия (перезапуск панели, обновление, диагностика).
- Вкладка «Система»: блокировка, сон, выход, перезагрузка, выключение.
- Шрифт интерфейса — Inter (пакеты `inter-font`, `ttf-nerd-fonts-symbols`), цифры и значки — JetBrains Mono Nerd.
- Super+Shift+R — запасной rofi. ПКМ по «n.» открывает настройки.

## 0.1.0-beta.4
- Waybar: сеть показывает «Интернет (скорость)», тултип с IP и ↓/↑ (конфиг из «КЛОДУ ЗАМЕТКИ»).
- SDDM: экранная клавиатура отключена (`InputMethod=` пустой в нашем конфиге; чужие активные `InputMethod=` комментируются с бэкапом и возвращаются при отключении).
- Виджеты: часы теперь аналоговые (со стрелками, дата по-русски), фон карточки часов починен (баг с классом "card hero"), длинные строки обрезаются «…» — виджеты больше не раздувает по ширине.
- Zsh: механизм личных конфигов (`~/.p10k.northling.zsh`) проверен, тесты проходят.

## 0.1.0-beta.3
- SDDM: включение находит и (с бэкапом) гасит чужие `Current=` (старая тема перебивала нашу); файл `zz-northling-theme.conf`; `northling sddm status|enable|disable`; точнее тест QML
- Панель: часы по-русски (клик — дата, наведение — календарь), раскладка EN/RU вместо `us`, убраны «подчёркивания» (столбик загрузки на 1%)
- Виджеты: плотнее фон карточек, `northling widgets city Название`, понятная заглушка погоды, дочерние процессы без `LD_PRELOAD` (мог ломать `nvidia-smi`)

## 0.1.0-beta.2
- Новый верхний бар «Острова» (Waybar): стеклянные блоки, точки-пилюли рабочих столов, метрики CPU/RAM/GPU, плеер
- Виджеты рабочего стола (GTK3 + layer-shell): часы, календарь, погода по городу из конфига, система, сеть, плеер
- Тема экрана входа SDDM; включается только после тестового запуска; откат из TTY
- Быстрое обновление `northling update` (без пакетов) и полное `--full`; `install.sh` на установленной системе предлагает обновление
- Защита: установка/полное обновление из графической сессии блокируются (гасили монитор) — только TTY или `--in-session`
- Тема Powerlevel10k пользователя (Light Segments) как основная
- Анимации Hyprland: пружинное появление окон, slidefade столов, вращающаяся рамка
- VS Code: `.vsix` и `install-windows.ps1`; выбор «официальный (AUR) / Code - OSS»
- NVIDIA-аудит: GBM, Vulkan, VA-API, версии Hyprland/драйвера (только чтение)
- Монитор по умолчанию `preferred` (исправление пользователя); `NVD_BACKEND` отключён (исправление пользователя)
