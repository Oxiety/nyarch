# Changelog

## 0.1.0-beta.9 (багфикс-версия по «КЛОДУ ЗАМЕТКИ»)
- Liquid Glass выпилен полностью (файлы, флаг, правила Hyprland, плитка, пункт в Пуске). Waybar снова запускается обычной командой.
- Центр управления: состояние плиток, громкости и яркости читается в фоне, окно открывается сразу (раньше subprocess блокировал открытие).
- Пуск: поиск с паузой 90 мс (список не пересобирается на каждую букву), пустой запрос показывает первые 80 приложений, в результатах до 40 строк.
- Диагностика (`northling diag`): новые разделы «6b. файлы SDDM» (видно, кто включает экранную клавиатуру) и «7b. Сеть и Steam» (DNS, IPv6, пинг, регион загрузки Steam).
- Проверка (`northling doctor`): предупреждает про bluetooth (служба и пакеты), dunst и KDE-уведомления (конфликт с swaync), активный InputMethod на экране входа.
- Файлы zsh (`dotfiles/zsh/p10k.zsh`, `zshrc`) объявлены официальными: p10k.zsh совпадает с присланным Light-Segments. Новый конфиг с логотипом Arch/монограммой «n.» в репо пока не попал — его нужно прислать файлом.

## 0.1.0-beta.8
- Норт — маскот системы: 9 стикеров с прозрачным фоном (`assets/north`). Виджет на рабочем столе (клик — другой стикер), в «Пуске» (каждый раз новый), на экране блокировки (hyprlock) и на экране входа SDDM.
- `northling mascot list|set ИМЯ|next|random` — выбрать активный стикер.

## 0.1.0-beta.7
- (выпилен в beta.9) Режим «Liquid Glass».

## 0.1.0-beta.6
- Центр управления (`northling control`, Super+A): громкость, микрофон, яркость, Wi-Fi, «не беспокоить», ночной режим (hyprsunset), игровой режим, mute.
- Игровой режим (`northling gamemode`, Super+G): без анимаций/теней/размытия/отступов, профиль питания «производительность».
- Снимки системы (`northling snapshot`): Timeshift; полное обновление делает снимок автоматически, если Timeshift настроен.
- «Пуск»: вкладка «Установка» (pacman + AUR, установка/удаление в терминале), вкладка «Буфер» (история cliphist, закрепы).
- Док с автоскрытием, подсветкой и увеличением иконок при наведении, индикатором запущенных окон.
- Экран блокировки: русская дата, погода, что играет, логотип, приветствие.
- Смена обоев по таймеру (`northling-wallpaper --loop`).
- Пакеты: `extras.txt` (timeshift, kdeconnect, hyprsunset, brightnessctl, power-profiles-daemon), `gaming.txt` (steam, mangohud, gamemode — по выбору).
- Не сделано сознательно: Plymouth (лезет в initramfs/загрузчик), курсор/иконки из AUR (нет проверки имён пакетов), палитра из обоев.

## 0.1.0-beta.5
- «Пуск» Northling (`northling start`, Super+R, клик по «n.»): лавандовый логотип «n.», строка поиска по приложениям, закреплённые приложения, калькулятор («2+2*3»), `> команда` в терминале, `? запрос` в интернете.
- Вкладка «Бинды»: гайд по всем горячим клавишам на русском, фильтруется поиском.
- Вкладка «Настройки»: переключатели виджетов, стиль часов, город погоды, выбор обоев с миниатюрами, быстрые действия (перезапуск панели, обновление, диагностика).
- Вкладка «Система»: блокировка, сон, выход, перезагрузка, выключение.
- Шрифт интерфейса — Inter (пакеты `inter-font`, `ttf-nerd-fonts-symbols`), цифры и значки — JetBrains Mono Nerd.
- Super+Shift+R — запасной rofi. ПКМ по «n.» открывает настройки.

## 0.1.0-beta.4
- Waybar: сеть показывает «Интернет (скорость)», тултип с IP и ↓/↑ (конфиг из «КЛОДУ ЗАМЕТКИ»).
- SDDM: экранная клавиатура отключена (`InputMethod=` пустой в нашем конфиге; чужие активные `InputMethod=` комментируются с бэкапом и возвращаются при отключении).
- Виджеты: часы теперь аналоговые (со стрелками, дата по-русски), фон карточки часов починен (баг с классом "card hero"), длинные строки обрезаются «…» — виджеты больше не раздувает по ширине.
- Zsh: механизм личных конфигов (`~/.p10k.northling.zsh`) проверен, тесты проходят.
