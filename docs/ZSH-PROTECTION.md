# Защита пользовательских конфигов Zsh

Northling Arch считает следующие файлы личными пользовательскими настройками:

- `~/.zshrc`
- `~/.p10k.zsh`
- `~/.p10k.northling.zsh`
- `~/.zshrc.local`

Установщик управляет только шаблонами из репозитория: `dotfiles/zsh/zshrc`
и `dotfiles/zsh/p10k.zsh`. Они устанавливаются с политикой `seed`:
создаются при первой установке, но если пользователь изменил установленный
файл, последующие установки и обновления оставляют его без изменений.
Файлы `.p10k.northling.zsh` и `.zshrc.local` репозиторий вообще не разворачивает.

Шаблон Zsh сначала загружает `~/.p10k.northling.zsh`, а если его нет —
использует `~/.p10k.zsh`. Дополнительные пользовательские команды загружаются
из `~/.zshrc.local`.

Перед обновлением `northling update` создаёт архив со снимком конфигов проекта
и всеми существующими личными Zsh-файлами из списка выше. Домашние файлы
попадают в каталог `home/`, а файлы XDG Config — в `config/` внутри архива
в `~/.local/share/northling/backups/`.

Проверка снимка:

```bash
bash tests/test-zsh-snapshot.sh
```

Архив — это страховочная копия. Обновлятор не восстанавливает из него файлы
и не перезаписывает пользовательские настройки.
