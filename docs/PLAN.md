# План и статус (Northling Arch)

## Сделано (beta.2)
Установщик/обновление/удаление, бэкапы с манифестом, Hyprland (Lua), Waybar «Острова», виджеты, SwayNC, Rofi, Kitty,
Zsh + p10k (тема пользователя), VS Code (+ .vsix для Windows), тема SDDM с безопасным включением, NVIDIA-аудит, тесты на моках.

## Не проверено на живой системе
Виджеты (GTK/layer-shell), QML-тема SDDM, новые Lua-анимации (`borderangle loop`, `slidefade`), имена пакетов в репозиториях.

## Дальше
1. Первый запуск на Arch → правки по логам (`northling diag`, `northling widgets status`).
2. Чёрный экран SDDM: по логам; кандидаты — ранний KMS NVIDIA, смена режима greeter.
3. Размытие панели/виджетов через layer-правила (после подтверждения синтаксиса Lua).
4. Недостающие фурри-обои (нужны файлы от пользователя).
