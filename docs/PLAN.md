# Northling Arch — технический план (v0.1.0-draft0)

Статус: **этап 0 готов, ждём результаты диагностики с твоего nyarch.**

## Что изменилось относительно ТЗ

| Пункт | ТЗ | Решение | Почему |
|---|---|---|---|
| Палитра | фон `#0C0C0C` | индиго-тёмный `#0E0A24 / #1C1155 / #342676` | ты хочешь гамму сайта + лавандовый; значения сняты со скриншота сайта |
| Dual boot | не упомянут | Windows и загрузчик **не трогаем**, диагностика читает ESP/efibootmgr | у тебя дуалбут |
| Обои | 3 стандартных + 1 фурри | 3 сгенерированных (оригинальные) + 2 твоих фурри (3-й/4-й слот — докинешь) | стоковые из сети шелл достать не может |
| Смена обоев | «без правки конфигов» | `swaybg` читает симлинк `~/.config/northling/wallpaper` | замена = перекинуть симлинк |
| VS Code | официальный | AUR `visual-studio-code-bin` | `code` в extra — OSS-сборка |

## Что проверено по официальной документации (wiki.hypr.land, 0.55–0.57)

- Конфиг — `~/.config/hypr/hyprland.lua`; `hyprland.conf` устарел с 0.55.
- API: `hl.monitor`, `hl.env`, `hl.config`, `hl.curve`, `hl.animation`, `hl.bind`, `hl.dsp.*`, `hl.window_rule`, `hl.on("hyprland.start")`, `hl.exec_cmd`.
- Раскладки: `kb_layout = "us,ru"`, `kb_options = "grp:alt_shift_toggle"`.
- NVIDIA: при драйвере ≥ 570.86.16 нужен только modeset (fbdev включён сам); env — `LIBVA_DRIVER_NAME`, `__GLX_VENDOR_LIBRARY_NAME`; для Electron — `ELECTRON_OZONE_PLATFORM_HINT=auto`.
- Свежий стабильный релиз: Hyprland 0.57.2 (9 ноября 2026, по данным Wikipedia).

## Открытые вопросы (честно: не проверено)

1. Точные имена пакетов в репо: `swaync`, `rofi` vs `rofi-wayland`, `ttf-jetbrains-mono-nerd`, `zsh-theme-powerlevel10k`. Ответит `northling-diag.sh`.
2. Синтаксис mouse-биндов (перетаскивание окон) и `focus` по направлению в 0.57 — сверить перед этапом 2.
3. Нужны ли `shadow.render_power`, `blur.vibrancy` и т.п. — не добавлены, т.к. не подтверждены в источниках.
4. Lua-конфиг и `require` модулей: пока один файл. Разобьём, когда проверим на живой системе.
5. Виджеты рабочего стола: кандидаты — **eww** (AUR/extra?) или **Quickshell**. Выбор после диагностики; в Waybar их не пихаем.
6. Чёрный экран ~3 сек: причина пока неизвестна, нужны логи (раздел 6 диагностики).

## Принципы безопасности (из ТЗ, соблюдаются с этапа 0)

- Диагностика — только чтение, без sudo.
- Windows, EFI-раздел и загрузчик не изменяем.
- Перед любой заменой конфига — бэкап в `~/.local/share/northling/backups/<дата>/`.
- Пользовательские обои (`wallpapers/furry/`, `~/Pictures/Wallpapers/`) не перезаписываются обновлением.
- AUR — только через paru под обычным пользователем.
